# 本地发音与音标练习

在 http://127.0.0.1:8765 的“练习内容”里选择：

- **短文朗读**：自由粘贴 3–200 个英文词，最长 120 秒。
- **单词 / 短语**：输入 1–5 个词，例如 think、this 或 modern technology，最长 20 秒。
- **音标专项**：直接输入英语 IPA，例如 `/θ/`、`/ð/`、`/ʃ/`、`/tʃ/` 或 `/iː/`，也可输入音标序列（最多 24 个音素）。支持 `/…/`、`[…]`；重音和长音符号可输入，但本版不评价重音或元音长短。

点击“开始录音”，读完后“结束录音”，再点击“分析这次练习”。也可上传录音。点击结果中的目标或单词，查看参考音素、模型识别与复听片段。“用当前模型重新分析”会另存一条结果，保留原记录。

## 练 th

- `/θ/`：think、three 中的常见读音。页面有“θ · think”按钮。
- `/ð/`：this、they 中的常见读音。页面有“ð · this”按钮。
- 单独输入 th 有歧义，系统会要求选择其中一种。
- 可先做音标专项，再切换到单词模式练例词。建议每次录 1–3 秒，避免贴麦吹气。

**孤立音素识别仍是实验功能，不能保证每次认对。** 测试中模型能识别 think 中的 θ，也能输出 sink 中的 s；但对截取出的孤立 θ 气流声可能漏识别，合成 this 中的 ð 也出现过误识别。系统保留未检出、证据不足和原录音，不把它们直接当成发音错误。支持输入音标，不等于已经可靠验证独立音素的发音正确性。

## 怎么理解结果

- **序列一致 / 识别到目标**：模型输出包含相应音素，不代表真人判定达标。
- **建议复听**：参考与模型输出有疑似差异，仍可能是识别错误、口音或词典变体差异。
- **证据不足 / 未检出**：无法可靠判断；未释放词尾、弱读等不直接扣分。
- 词典主要采用北美英语读音，未覆盖所有英语口音。
- 发音尚无校准分数，不把识别置信度冒充发音分。专项模式没有内容、流利度或总分。
- 短文 Practice Score 目前只聚合已有内容和流利度指标，覆盖 70% 的设定维度；即使显示 98，也不是发音 98，更不能换算成 PTE 官方成绩。

## 本机运行与验证

RTX 5060 Laptop 8GB 运行 Whisper 英文转写；CPU 运行独立音素模型。模型已下载，运行时不上传录音，无需 API 密钥。使用 `start-windows.cmd` 启动，`stop-windows.cmd` 停止。

- 40 项自动测试通过，依赖一致性与全部前端脚本语法检查通过。
- 实际模型完成单词、音标目标、不同声音对照和用户原录音分析。
- 用户 10.68 秒原录音已另存新版结果；已加载模型后的音素推理约 1.32 秒。单次测量不构成速度保证。
- 原记录 JSON 保持不变；专项练习不混入短文语速趋势。
- 网页模式切换、音素表格和片段播放已检查。合成语音与自动测试只验证功能，不是人工评分准确率验证。
- 验证结论见 `docs/validation.md` 和算法报告；本地录音与练习记录不进入公开仓库。

音素模型使用完整 float32 精度；固定版本和 SHA-256 位于 `models/phoneme-en/manifest-fp32.json`。更新前的数据库及源代码备份位于工作区 `work/pronunciation-backup`，原桌面 ZIP 未修改。

模型来源：[Meta 原始音素模型](https://huggingface.co/facebook/wav2vec2-lv-60-espeak-cv-ft)、[ONNX Community 转换](https://huggingface.co/onnx-community/wav2vec2-lv-60-espeak-cv-ft-ONNX)。它输出音素序列，不是经过 PTE 标注校准的评分。
