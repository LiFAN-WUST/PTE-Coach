# PTE Coach 维护流程

GitHub 私密仓库保存源代码、测试、文档和模型配置。`.venv`、缓存、日志、SQLite 练习记录、录音和大型模型权重不进入 Git 历史；完整本地运行版在桌面 ZIP 中。

## 在原电脑恢复本地运行

从桌面的 `PTE-Coach-Local-2026-09-16.zip` 解压后，保留其中的 `models`、`.venv` 和 `data`。GitHub 拉下来的源代码可覆盖 `app`、`scripts`、`tests`、`docs` 和启动脚本，但不要覆盖本地 `data`。

如果重新准备模型，使用项目的依赖安装和模型下载说明；当前离线 GPU 启动脚本要求 `models/small.en` 和 `models/phoneme-en/onnx/model.onnx` 存在。

## 每次更新

1. 先停止正在运行的本地服务，或至少等当前录音分析完成。
2. 只提交源代码、测试、文档和配置；检查 `git status`，确认没有 `data`、`.env`、`.venv`、日志或录音。
3. 运行 `python -m pytest -q` 和 `npm run check`。
4. 写清本次改动和验证结果，再提交并推送到私密仓库。
5. 需要更新桌面运行包时，重新生成 ZIP，并单独核对 ZIP 完整性。

后续你说“更新 PTE Coach”时，我会让 Luna 子智能体先做一次变更审查，再由主流程完成必要修改、测试和推送。Luna 不会在你没有发起更新时自行后台改仓库。
