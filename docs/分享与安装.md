# 分享与安装

这个仓库现在公开，别人可以直接查看源代码并下载模型。它是本地单用户程序，不是在线网站；每个人都需要在自己的电脑上安装依赖，录音也只保存在自己的 `data` 文件夹。

## Windows 推荐安装

1. 在仓库主页点击 **Code → Download ZIP**，解压到一个没有中文或空格的目录；也可以使用 `git clone https://github.com/LiFAN-WUST/PTE-Coach.git`。
2. 安装 Python 3.12 和 FFmpeg，并确认在 PowerShell 中运行 `ffmpeg -version` 有输出。
3. 打开仓库的 [模型 Release](https://github.com/LiFAN-WUST/PTE-Coach/releases/latest)，下载 `model.bin` 和 `model.onnx`，按 [模型下载清单](../models/模型下载.md) 放到指定目录。
4. 在项目目录打开 PowerShell，安装 CPU 依赖：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

5. 启动本地服务。下面的设置会启用本地音素模式和两个自定义练习模式：

```powershell
$env:PTE_DEVICE='cpu'
$env:PTE_COMPUTE_TYPE='int8'
$env:PTE_ASR_MODEL=(Resolve-Path 'models/small.en').Path
$env:PTE_PRONUNCIATION='local'
$env:PTE_PHONEME_MODEL=(Resolve-Path 'models/phoneme-en').Path
$env:PTE_DATA_DIR=(Join-Path (Get-Location) 'data')
\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8765
```

6. 浏览器打开 `http://127.0.0.1:8765`，允许麦克风权限，就可以练习短文、单词和音标。

如果拿到的是作者提供的“Windows 便携版”压缩包，不需要重复安装 Python 或依赖：完整解压后直接双击 `start-portable.cmd`；结束使用时双击 `stop-portable.cmd`。便携包默认使用 CPU，首次加载模型可能需要几十秒。

## 有 NVIDIA 显卡时

先安装锁定的 GPU 依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-local-lock.txt
```

确认 CUDA/cuDNN 和显卡驱动可用后，可以双击 `start-windows.cmd`。如果启动失败，回到上面的 CPU 启动方式；CPU 方式更适合第一次验证。

## 分享时要告诉对方

- 当前发音诊断仍是实验功能，不能当作 Pearson 官方分数。
- 练习录音和历史只写入对方自己的 `data`，不会自动上传。
- 不要把自己的 `data`、`.env` 或 `.venv` 一起发给别人；模型 Release 和源代码已经足够重新安装。
