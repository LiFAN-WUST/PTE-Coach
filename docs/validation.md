## 已知工程限制

- 单个线程串行推理，没有强制杀死模型推理的独立进程超时；极端底层模型卡住需要重启服务。重启会将未完成任务标成失败，保留音频。
- 20MiB 文件流限制与 Content-Length 检查用于本机使用；不是公网反滥用网关。不要公开部署。
- 音高测量的置信度门限、停顿和评分阈值为启发式，需用真实学习者数据校准。
- 使用字典的音节估计会选择一个词典变体；没有实测音节分割。错序仅通过编辑操作体现。
- UI 自适应样式和媒体片段播放代码已实现，仍需目标浏览器手动验收。

## 目标电脑验收步骤

1. 启动后检查首页；录制 10–20 秒、清晰但自然的 RA。
2. 确认结束录音后麦克风占用释放、试听可播、提交有状态提示。
3. 点击词与候选停顿，确认定位大体正确；录制一次故意漏词、一次加入 1 秒句内停顿。
4. 检查差异、停顿标记和证据；不要要求边界帧级精确。
5. 刷新历史页，确认图表尺寸不随刷新增长、记录可重开。
6. 重启服务，确认记录仍在；备份 data 目录。
7. 如启用 Azure/LLM，另行验证服务返回，核对云端发送提示。
