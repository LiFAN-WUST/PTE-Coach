# 本地发音算法第二轮改进与验证

日期：2026-09-16。版本：phone-evidence-v2。

## 结论

本轮修复了对齐和提示筛选中的问题，但**发音纠错仍未通过有效性验收**。当前可用作录音、内容核对、音素对照和复听工具，不能当成可靠的发音裁判。没有新增发音分，也不能预测 PTE 成绩。

## 实际改动

1. 对照识别词的录音时间限制音素匹配范围，减少跨词错配。词边界仍是 ASR 估计，并非人工精确边界。
2. 时间与词序不能一致映射时，不输出该词的自动错误候选。错误、遗漏或未知词仍保留原始证据。
3. 元音与辅音的不合理配对改为未对齐项，不把它描述成确定的替代发音。
4. 只保留有限的辅音对比候选，并要求周围音素有足够匹配；词尾未释放、弱读和低可信输出继续保守处理。
5. 对候选改变录音上下文再识别一次，只有声音和时间位置都稳定才保留。两次使用同一个模型，**这只是稳定性检查，不是两位独立专家确认**。
6. 加入有效性检查状态：目前 diagnostic_ready=false，自动教练不根据音素候选给出纠错建议；用户仍可主动展开录音与音标对照。

## 人工标注录音对照

来源：[SpeechOcean762 官方仓库](https://github.com/jimbozhang/speechocean762)、[发布方 Hugging Face 数据集](https://huggingface.co/datasets/mispeech/speechocean762)。该语料由五名专家独立评分，包括儿童及成人的英语学习者录音。

选样在运行模型前确定：test split 中第 0、250、500……2250 行起，各取连续 5 条，共 50 条、333 个词。不是全语料评测，也不是有代表性的随机抽样。模型不使用人工标注作输入。

本次把人工词准确度小于 7 作为“需要纠错”的操作性标准：按语料说明，7–9 主要表示口音，低于 7 才进入部分音素错误等级。这是本次验证标准，不是考试标准；人工评分也存在差异。

| 最终版本对照 | 旧版 | 新版候选算法（展示限制之前） |
|---|---:|---:|
| 人工判为有问题且被标出的词 | 1 | 0 |
| 人工未判为问题却被标出的词 | 34 | 0 |
| 漏掉的人工问题词 | 6 | 7 |
| 总提示词数 | 35 | 0 |

**零误报来自本批样本没有留下任何候选，不能解释成 100% 准确。** 新版漏掉了全部 7 个问题词，提示精确率无定义，检出率为 0%。样本中明确错误较少，也不足以验证每一种辅音对比。因此保留“未验证”状态，不开放自动发音纠错。

第一遍尚未修正元音／辅音配对的候选版本出现过 1 个误报；最终版重新运行全部样本，结果以上表为准。此为探索性验证，本批样本不能再作为今后调参后的独立验收集。

逐词原始结果、年龄分组指标见 `algorithm-v2-benchmark.json`。测试录音没有加入用户练习历史，也没有上传用户录音。

## 软件检查与记录保护

- 48 项 Python 测试通过，2 项前端逻辑测试通过，前端语法检查通过。
- 新增测试覆盖：跨词时间约束、元音／辅音错配、整词匹配不足、上下文不稳定、缺失词边界，以及未验证状态不能变成自动诊断。
- 单元测试通过只证明实现符合这些规则，不证明发音评测准确。
- 新分析另存一条历史，原记录不覆盖。更新前数据库保存在工作区 `work/algorithm-v2/history-before-v2.sqlite3`。
- 固定选样脚本、下载文件校验值及对照程序保存在工作区 `work/algorithm-v2/`。旧算法源码也已保留，比较时使用其原有对齐与提示规则。

## 仍需完成的算法工作

需要采用或训练针对学习者发音、带人工标注监督的评测模型，并在独立留出的语料上验证准确率、误报率及检出率。还需覆盖不同口音、麦克风、噪声、弱读和孤立音素；分项通过后才能逐项开放纠错建议。仅靠通用音素识别结果与词典做差异对照，尚不足以承担这个任务。
